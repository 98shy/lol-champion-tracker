# 나의 챔피언 풀

리그 오브 레전드의 모든 챔피언을 작은 1:1 초상화로 확인하고, 플레이한 챔피언과 현재 승패 및 판당 별풍선 결산을 기록하는 웹 페이지입니다.

검색은 띄어쓰기를 구분하지 않으며 챔피언 이름, 일반적인 축약형과 초성을 지원합니다.

## 실행

`index.html`을 브라우저로 열면 바로 사용할 수 있습니다. 로컬 서버로 실행하려면 이 폴더에서 아래 명령을 사용하세요.

```bash
python3 -m http.server 8080
```

그다음 `http://localhost:8080`에 접속합니다.

챔피언 명단과 초상화는 Riot Data Dragon에서 불러오므로 인터넷 연결이 필요합니다. 선택 기록은 해당 브라우저의 `localStorage`에만 저장됩니다.
